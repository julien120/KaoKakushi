# フィクスチャ画像のライセンス

- `portrait.jpg` — MediaPipe の公式サンプルアセット (https://storage.googleapis.com/mediapipe-assets/portrait.jpg)。Apache License 2.0 (google-ai-edge/mediapipe プロジェクトのテストデータ)。
- `two_faces.jpg` — 上記 `portrait.jpg` を 2 枚並べて合成した派生物（`tools/` 参照）。同じく Apache License 2.0 由来。
- `burger.jpg` — MediaPipe の公式サンプルアセット (https://storage.googleapis.com/mediapipe-assets/burger.jpg)。Apache License 2.0。顔なしコントロール画像として使用。
- `group_photo.png` — ユーザー提供のプライベート写真（小さい顔の検出回帰テスト用）。**git 管理外・ローカル専用**（.gitignore 済み、再配布不可）。ファイルが無い環境では該当テストは自動 skip される。
- `big.jpg` / `rotated.jpg` / `note.txt` — このプロジェクトでスクリプト生成した合成フィクスチャ。
